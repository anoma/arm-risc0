# Compliance Circuit

This crate contains the RISC Zero compliance circuit and its local benchmark.
Succinct STARK proofs are generated by default.

## Benchmark Cases

| Case | Description |
|------|-------------|
| `empty_tree` | No precomputed kind tree — circuit falls back to `hash_to_curve` per proof |
| `file_tree`  | Loads `kind_tree.json` — resolves kind points via tree lookup |

The trailing number in each benchmark name is the **batch size** (number of consumed/created resources).

## Running

Local (CPU):

```bash
cargo bench --features prove --bench compliance
```

CUDA:

```bash
cargo bench --features prove,cuda --bench compliance
```

Fast iteration without real proof generation:

```bash
RISC0_DEV_MODE=1 cargo bench --features prove -p compliance
```

## Results

| num | `empty_tree` | `file_tree` |
|------:|:-------------:|:------------:|
|     1 |    2.125 s    |   808.7 ms   |
|     2 |    3.084 s    |   844.7 ms   |
|     4 |    6.320 s    |   1.235 s    |
|     8 |   11.464 s    |   1.288 s    |

`file_tree` amortizes the `hash_to_curve` cost across the batch, keeping proving
time nearly flat up to 8 proofs. `empty_tree` scales roughly linearly with batch size.
